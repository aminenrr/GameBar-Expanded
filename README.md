# Controls Hub

One Xbox Game Bar widget for Alien Controls, Dolby Controls and DualSense Controls: switch the Alien preset, Dolby Atmos profile and DualSense mode without leaving the game, with PlayStation prompts and per game profiles.

Status: P0 spike (widget, broker, dummy app, spike tools) built and waiting for the hardware test, see [docs/P0-TEST.md](docs/P0-TEST.md). [AGENTS.md](AGENTS.md) has the full plan and status, [design/mockups](design/mockups) the signed off mockups.
