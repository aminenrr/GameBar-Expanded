P0 spike build for testing on the laptop. Not a usable app yet: it proves the risky parts (widget in Game Bar, broker, pipe push, nav without focus, Win+G, HidHide timing).

**Downloads**

* `ControlsHub-0.1.0-p0-package-x64.zip`: the MSIX, its test certificate, framework dependencies, `install.ps1`, `uninstall.ps1` and `P0-TEST.md`.
* `ControlsHub-0.1.0-p0-tools-x64.zip`: `DummyApp`, `SpikeTests` and an unpackaged broker for `--console`.
* The `.msix` and `.cer` are also attached on their own.

**Install**: extract the package zip, open Windows PowerShell as administrator in that folder, run `powershell -ExecutionPolicy Bypass -File .\install.ps1`. Then follow `P0-TEST.md` and fill in its results table.

The package is signed with a throwaway test certificate made by CI for this build only. `install.ps1` trusts it in LocalMachine\TrustedPeople; `uninstall.ps1 -RemoveCerts` removes it again.
